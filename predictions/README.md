# 预测台账

本项目的**反馈回路**：所有可验证判断当场登记、事后对账、按条目归因。
禁止事后补记、改写历史行、只记对的——错得越清楚，方法论迭代越快。

## 字段说明（predictions.csv）

| 字段 | 说明 |
|---|---|
| 日期 | 判断作出当日 |
| 代码 / 名称 / 资产类型 | 标的（stock / etf / of_fund） |
| 方向 | 看多 / 看空 / 中性观望 |
| 判断内容 | 一句话写清判断什么（如"缩量回踩 20 日线后启动"） |
| 依据条目 | knowledge/distilled 的方法论编号（R-xxx / J-xxx），盘感判断标"盘感" |
| 触发/目标条件 | 判断成立时应该看到什么（可验证的具体条件） |
| 失效/止损条件 | 判断被证伪的信号 |
| 时间框架 | 几个交易日 / 几周内验证 |
| 验证日期 / 结果 | 到期后填写：对 / 错 / 部分 / 未触发 |
| 盈亏幅度 | 若按判断操作，理论盈亏（%） |
| 复盘备注 | 错在哪、对在哪、条目要不要改 |

## 评分规则（周度执行，写入 reports/weekly/）

- 统计**命中率、平均盈亏比**，并**按方法论条目分组**看表现
- 持续表现差的条目标记"待证伪"，进入方法论修订评审
- 只统计"当时写下的判断"；会话中口头倾向未登记的，视为没有判断
