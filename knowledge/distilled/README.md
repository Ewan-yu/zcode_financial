# 提炼后的方法论

从 `../raw/` 提炼的结构化知识，按主题分文件：选股逻辑、买卖点规则、情绪周期、
风控纪律、基金 ETF 等。

## 条目规范

每条方法论一个编号：**R-xxx**（硬规则，可量化、可编程）或 **J-xxx**（判断框架，需盘感综合）。

字段：内容 ｜ 来源（raw 文档 + 章节）｜ 类型 ｜ 数据需求（映射到哪个 MCP 工具）｜
状态（草稿 / 已验证 / 待证伪 / 已证伪）

## 计划产出

- `methodology.md` — 方法论总纲（所有条目的索引与分类）
- `data-source-map.md` — 每条经验的数据源映射表 + 数据盲区清单（哪些数据插件不直接覆盖，
  需要新闻检索 / 问财兜底）
