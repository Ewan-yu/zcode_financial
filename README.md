# A股 · 基金 · ETF 投资分析与跟踪系统

个人投资研究工作台：本人经验方法论 + AI 分析判断 + 金融数据插件（同花顺 / 万得 / 天眼查），
覆盖日常分析、盯盘、趋势跟踪、买卖点参考、公司研究、策略制定与回测。

> **定位边界**：本系统输出的是分析、信号与证据，辅助决策；最终决策与下单由本人作出。
> 所有可验证判断记入预测台账（`predictions/`），事后对账评分——这是策略迭代的反馈回路。

## 架构：四层混合（技能为核）

| 层 | 载体 | 职责 |
|---|---|---|
| 知识层 | `knowledge/` + `.zcode/skills/`（项目级技能） | 经验沉淀为硬规则与判断框架，技能化后随用随调 |
| 数据层 | `data/` | MCP 取数落盘：日度快照 + 缓存，跨日对比 / 回测 / 对账的数据底座 |
| 调度层 | 定时任务（盘前 / 尾盘 / 盘后） | 盯盘自动化，无需每天手动触发 |
| 输出层 | `reports/` + 会话内交互看板 | 生成式报告与看板，按日期积累 |

程序（`tools/`）只承担机械计算（指标、信号扫描、回测引擎），由技能调用——判断的事交给 AI。

| 目录 | 内容 | 谁写入 |

## 每日节奏（规划，第 2 步上线定时任务后生效）

- **08:45** 盘前简报：隔夜要闻、自选公告扫描、当日关注点
- **盘中** 随时召唤：单票快照 + 分钟形态 + 方法论判断
- **14:40** 尾盘扫描：自选异动、买卖点信号提示
- **15:30** 收盘复盘：指数与情绪、自选逐评、次日计划 → 存档 `reports/daily/`
- **周末** 预测台账评分、基金/ETF 周报、深度公司研究、策略回测

## 基金 / ETF 的整合方式

架构不变，三处落地：

1. **统一自选池**：`portfolio/watchlist.json` 用 `asset_type` 字段区分 `stock / etf / of_fund`，一个池子管理。
2. **数据通道分流**：场内 ETF/LOF 有实时行情，纳入每日盯盘复盘循环（万得 fund 接口，含折溢价、IOPV）；
   场外基金净值日更一次、盘中无意义，降频为**周度跟踪**（净值、收益、回撤、持仓风格漂移）。
3. **复用现成能力**：基金研究深挖（筛选 / 画像 / 经理）直接用已装的 pick-funds 插件，
   本项目只做"跟踪与整合"（周报、与股票仓位的组合视角），不重复造。
