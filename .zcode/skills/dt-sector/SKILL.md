# 板块内标的对比（短线）

> 知识基座：`knowledge/distilled/dt/`（market.md 环节判定 / targets.md 五维选股 /
> volume-price.md 承接力专章）。核心前提：**板块环节决定对比的意义**——启动/发酵期
> 板块对比选优，高潮/退潮板块只列不选（DT-J-028）。
> **模型分层**：第 1-3 步取数落盘与硬过滤可委派 `dt-scout`（GLM-5.3-Flash）；
> 第 4 步起（评分/排序/结论）必须主会话或 dt-trader 用主力模型执行。

## 执行规范（硬约束——违反任一条即执行失败，返工重做）

1. **先落盘后分析**：所有 MCP 取数立即写入 `data/snapshots/<D>/`（当日）或 `data/cache/`
   （低频），分析层只读落盘文件；报告中每个数字都要能指到具体快照文件或当次工具返回。
2. **缺数如实标注**：取不到写「数据缺失（原因）」；禁止估算、编造、沿用旧值、
   用"约/大概"模糊带过。
3. **指标必计算**：承接力结论必须实际运行 `tools/indicators.py` 产出数值，禁止只按
   涨跌幅排名叙事；指标与读图冲突时以指标为准。
4. **判断必挂依据**：可验证判断标注条目编号；无条目支撑单独标"盘感"。
5. **模板锁定**：输出逐节按 `templates/dt/sector-compare.md` 填充，禁止增删章节；
   交付前 `python tools/report_lint.py <报告> --type sector` 自检通过。
6. **逐标的全写**：对比池内每只都进矩阵与点评，禁止只写前两名"等其余同理"。
7. **看板无代号**：用户可见看板用自然语言；条目编号只进 md 报告与台账。

## 流程

### 第 0 步：环境准备

- 确认交易日 D；建 `data/snapshots/D/`、`reports/daily/D/`
- 当日已有 `sentiment.json` 或晚间复盘 → 直接引用其 L3 板块环节判定，不重算

### 第 1 步：板块环节判定（DT-J-010 / DT-J-028）

- 问财：`{D}{板块名}概念涨停的股票，显示连续涨停天数、换手率、流通市值`
- 板块整体热度与量能：`sector_data`（板块ID路径）或问财板块涨幅；板量分类
- 判定环节 = {启动/发酵/高潮/退潮}；入池门槛四条件（持续性逻辑 / 龙头梯队 /
  板块量能 / 资金连续性）逐项过
- **高潮/退潮 → 第 4 步结论一律"回避/仅记录"，不做选优**，并在报告第 0 节说明原因

### 第 2 步：对比池确定

- 入池口径：板块内今日涨停 + 涨幅前 N（问财一句原话记录进报告）；剔除 ST、
  一字连板（单列观察池）、退潮环节个股
- 对比池 3-8 只为宜；不足 3 只时如实说明并降低对比结论置信度

### 第 3 步：逐标的取数（可委派 dt-scout，全部落盘）

每只固定取四件：
1. 行情快照：现价 / 涨跌幅 / 换手 / 量比 / 流通市值（万得 `get_stock_price_indicators`）
2. 当日分钟K（万得 `get_stock_kline`，`bars_from_wind_kline` 转换）→
   `tools/indicators.py` 承接指标（上行量占比 / 乖离 / 脉冲性质）
3. 近 20 日日线（`get_stock_performance`）→ 启动结构判断
4. 连板高度（问财返回字段）

### 第 4 步：对比矩阵与评分

- 填对比矩阵（模板第 2 节固定列，一只一列）
- 每只必须有承接指标数值——**禁止只按涨跌幅/连板高度排名下结论**
- 五维评分（DT-J-027）逐只打分并记入矩阵末行

### 第 5 步：结论与台账

- 排序 + 建议（重点观察（可入池）/ 普通观察 / 回避）+ 一句话理由
- 板块门槛通过且总分 ≥4 → 按 dt-review 第 5.5 步入池规则执行（A 级默认加自选）
- 产生可验证判断 → 当场追加 `predictions/predictions.csv`

### 第 6 步：报告与看板

- 存档 `reports/daily/D/板块对比_{板块}.md`（模板逐节填充 + 附录A 数据出处）
- 看板基于 `templates/dt/dashboard.html`：对比矩阵表（红绿着色）+ 关键指标横向条形
  对比 + 结论卡；交付规范同 dt-review 第 7 步（会话可视化目录 + 最终回复
  `::visualize{"path":...}` 引用 + 静态副本存档）
- 自检：`python tools/report_lint.py <报告> --type sector --dashboard <看板>`

## 纪律

- 环节不明时先完成环节判定再谈对比；拿不准就标注"环节存疑"，全部结论降级为观察
- 对比不等于推荐买入；介入条件另行按 timing-buy 条目校验（DT-R-014/015）
