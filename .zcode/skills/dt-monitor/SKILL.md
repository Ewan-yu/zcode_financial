# 盘中盯盘（短线）

> 知识基座：`knowledge/distilled/dt/volume-price.md`（专章）+ timing-buy/sell 条目。
> 仅交易日盘中有效；分钟K用同花顺 `stock_highfreq_quotes`（highfreq 模式，1分钟），
  快照用 real_time 模式（非交易日返回最近交易时刻数据，可用于盘后补看）。

## 模式一：单票快诊（用户点名某股）

1. **取数**（并行）：
   - `stock_highfreq_quotes` real_time：`最新价,涨跌幅,成交量,成交额,换手率,开盘价,最高价,最低价`
   - `stock_highfreq_quotes` highfreq 1 分钟K：`开盘价,最高价,最低价,收盘价,成交量,成交额`，
     start_time=当日 09:30，end_time=当前时刻
   - 昨收与昨日前收盘涨停判断：`get_stock_performance` 最近 2 日
   - 近 5 日分钟K（量比基数）：读 `data/snapshots/` 本地，无则取日线近似并标注
2. **计算**（调 `tools/indicators.py`）：
   - `vwap_series` + `bias` → 黄线位置与乖离
   - `updown_volume` → 上行量占比
   - `pulse_events` → 脉冲与回撤测试（日成交额<5亿的票 mult=5）
   - `volume_ratio_at` → 同期量比
   - 持仓票：`state_matrix`（状态灯）+ `sell_check_sanbuqu`（三部曲第一条）
3. **判定顺序**（短路径，命中即出结论）：
   - 持仓：极端止损（-9%，DT-R-009）→ 放量破黄线立即走（DT-R-045）→
     三部曲时间窗（DT-R-001/002/003）→ 状态矩阵（DT-J-022）→ 尾盘规则（DT-R-007/012）
   - 候选买入：三模型校验（DT-R-015）→ 四形态量化触发（DT-J-023）→
     低吸位置约束（DT-R-014：≤3%，强势≤6%）→ 上午完成（DT-R-019）
4. **输出一屏**：
   ```
   【600825 新华传媒 10:42】现价 15.16 (+10.0%)
   量价：VWAP 14.98 | 乖离 +1.2% | 同期量比 2.1 温和放量 | 上行量 63%
   脉冲：10:10 放量4000万 → 回撤0.1% 承接强
   状态：🟢 绿·强承接（DT-J-022）
   结论：持有 / 卖出检查：三部曲第X条…
   依据：DT-J-022, DT-R-045, DT-R-001
   ```
5. 产生的可验证判断当场追加 `predictions/predictions.csv`。

> 需要图形看板时按 dt-review 第 7 步的可视化产出规范执行（加载 visualize 技能 +
> 会话目录 + **最终回复中引用链接**，否则用户看不到）。单票快诊默认一屏文本优先，速度为主。

## 模式二：自选池扫描

1. 读 watchlist（status ∈ {观察中, 重点, 持仓} 的 stock + etf；观察票是主对象）。
2. 批量 real_time 快照（一次多码逗号分隔）。
3. 标记异动：量比突变（>2 或 <0.5）、速涨（5 分钟涨幅）、触涨停/跌停、
   持仓票触发红灯条件（先粗筛后对命中票走模式一深诊）。
4. 输出优先级排序表：命中条件 + 建议动作（深诊/执行卖出/关注）。

## 模式三：尾盘检查（14:40 触发或手动）

- 持仓票逐只：三部曲终检（当日红盘确认历史、涨停确认）+ 尾盘卖出预告清单
- 对照早盘预判（predictions 今日行）打分：判涨实涨/判涨实跌/判跌实涨（认错介入提示）/判跌实跌
- 简报输出 + 台账"验证日期"列回填准备

## 注意

- 一字板：无分时结构，只报封单/开板事件（DT-R-005 口径，买一量近似封单）
- 分钟K成交量 null = 零成交（一字/停牌段），计算已按 0 处理
- 快照在非交易日返回最近交易时刻——盘后复盘可复用本技能
