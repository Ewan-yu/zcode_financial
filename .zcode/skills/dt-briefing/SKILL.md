# 盘前简报（短线）

> 输入依赖：前一交易日的 `dt-review` 产物（候选清单 + 预判台账）。没有昨日复盘时提示并做简化版。

## 执行规范（硬约束）

1. **消息必检索**：隔夜要闻/公告只来自当次工具返回（万得 `get_financial_news` /
   `get_company_announcements`），禁止凭记忆复述；每条注明来源与检索时间。
2. **先落盘后引用**：昨日情绪直接读 `data/snapshots/<D-1>/sentiment.json`，不重算、
   不凭印象改口。
3. **缺数如实标注**：取不到写「数据缺失（原因）」，禁止估算编造（外盘数据不可得
   就明说，不用"大概"补）。
4. **模板锁定**：完整存档逐节按 `templates/dt/pre-briefing.md` 填充，交付前跑
   `python tools/report_lint.py <报告> --type briefing` 自检。
5. **判断留痕**：基调修正等可验证判断当场经 `db.py add-prediction` 入台账（权威源）。

## 流程（08:45-09:15 窗口）

1. **隔夜要闻**（DT-J-010 催化密度）：
   - 万得 `get_financial_news`：宏观（美联储/政策）+ 昨日主线题材跟踪
   - 有重大变化时评估对今日基调的修正（情绪阶段的边际变化）
2. **自选池公告扫描**（排雷）：
   - 万得 `get_company_announcements`：watchlist 全部标的，筛停复牌/减持/业绩预告/监管函
   - 命中即标注风险动作（持仓票触发卖出预案，候选票降级/剔除）
3. **昨日候选回顾**：
   - 读 `reports/daily/D-1/晚间复盘.md` 的 A/B 级清单与预判台账今日行
   - 每只候选列出：预判内容 + 竞价确认条件（DT-J-006：高开分档 × 竞价量匹配）
4. **竞价观察要点**（09:15 后可增量更新）：
   - 竞价量对比：`auction_amount()` 与前 1-2 日竞价额对比（萎缩一半则当日预期下调，DT-R-018）
   - 高开分档判读（0-2% 看承接 / 2-4% 温和 / 4-7% 强势须量配 / 7%+ 只看封单质量）
5. **输出简报**：会话中先给一屏精简版——今日基调（情绪阶段 + 隔夜边际变化）、
   公告风险清单、候选观察表（预期开盘 / 确认条件 / 放弃条件 / 仓位上限）、竞价三问
   提醒（预期是什么？低于/高于预期怎么办？DT-J-013）。
6. **完整存档**：逐节填充 `templates/dt/pre-briefing.md`，存 `reports/daily/D/盘前简报.md`，
   跑 `python tools/report_lint.py <路径> --type briefing` 自检通过才算交付。

## 纪律

- 简报只给观察框架与预案，不替用户做开盘决策；执行规则在盘中由 dt-monitor 判定
- 预判与开盘现实的偏差 = 认错信号（DT-J-004），简报中显著标注
