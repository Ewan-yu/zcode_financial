# 晚间复盘（短线）· 七步流程

> 知识基座：`knowledge/distilled/`（先读 `00-index.md`；本技能主要引用 DT 域与 dt/volume-price.md 专章）。
> 默认复盘"最近一个交易日"（非交易日自动回退到上一交易日）。
> 全程引用条目编号作为依据，无条目支撑的判断标注"盘感"。

## 第 0 步：环境准备

1. 确认交易日 D（问财查询用日期，格式 YYYYMMDD）与 D-1 交易日。
2. 读 `portfolio/watchlist.json`（持仓与跟踪标的）。
3. 建目录 `data/snapshots/D/` 与 `reports/daily/D/`，本技能所有取数先落盘再分析。

## 第 1 步：情绪定位（DT-J-017 / DT-R-030）

并行取数（已实测可用）：
- 问财①：`{D}涨停且非ST的股票，股价在60日线上方，显示连续涨停天数、换手率、流通市值`
- 问财②：`{D}跌停且非ST的股票`
- 问财③：`{D-1}涨停的股票，显示{D}的涨跌幅和连续涨停天数`（晋级率与溢价原料）
- 万得指数快照：`000001.SH`，指标 `最新成交价,涨跌幅,成交额,上涨家数,下跌家数`

用 `tools/indicators.py` 的 `sentiment_stats()` 聚合，输出六项指标与近 20 日对照
（历史值读 `data/snapshots/*/sentiment.json`，无历史则从今日开始积累），
判定情绪周期阶段（冰点/启动/发酵/高潮/退潮）→ **给出明日操作基调**。
注意：连板高度高但晋级率低 + 大面积负溢价 = 退潮确认信号（不能只看高度）。

## 第 2 步：主线识别（DT-J-010 / DT-J-012）

- 从问财①结果按"同题材涨停家数"聚类（用股票简称/行业常识+必要时问财补查所属行业）。
- 板块热度：`sector_data`（板块ID路径）或问财板块涨幅。
- 新闻催化：万得 `get_financial_news` 检索当日主线相关要闻，判断催化密度。
- 输出：主线清单（主线/支线），每条标注题材分级（政策级/产业级/事件级/疑似一日游）与所处环节。

## 第 3 步：涨停池初筛（DT-R-022/023/024）

问财①结果即初筛池。二次过滤：
- 剔除一字连板（开=高=低=收 且 量极小）→ 单列为"观察池"（缩量板最强但难上车，DT-R-047）
- 60 日线上 + 5/10 日线向上（问财①已含 60 日线；5/10 线对候选逐票用日线核对）
- 实际流通市值：问财返回的"a股市值(不含限售股)"为流通口径，再用
  `get_stock_shareholders` 前十大持股比例 + `actual_free_float()` 换算实际流通（股东数据走 data/cache，7 天过期）

## 第 4 步：选入量价评估（DT-J-027 五维，逐票）

对过滤后候选（控制 5-15 只）逐票：
1. **启动结构**：`get_stock_performance` 取近 20 日日线 → 地量后首放 or 高换再放
2. **量能节奏**：启动以来量能递增/骤放/紊乱（日线成交额序列）
3. **位置安全边际**：累计涨幅、距 60 日线空间（问财①已给差值）
4. **回调质量**：途中回调日缩量 or 放量
5. **当日确认**：板量类型（`当日量/近5日均量`，DT-R-047 分档）+ 板质量（封板时间、开板次数，
   从分钟K判断——非交易日用日线+龙虎榜近似）+ 无背离（DT-R-048）
6. 龙虎榜佐证：问财 `{D}龙虎榜净买入金额排名前10的股票`（已实测可用）比对候选是否在榜
持仓与连续跟踪标的同时执行**日级持有复查**（DT-J-024 五问）。

## 第 5 步：候选定级

- **A 级（明日重点）**：主线 + 五维≥4 优 + 位置好。给出：观察价位区、介入条件（DT-R-014/015 约束）、
  失效条件
- **B 级（备选）**：五维 3 优或支线题材。降仓位预期
- **剔除**：记录剔除原因（高位加速/放量回调/背离/无承接结构）

## 第 6 步：次日预判登记（DT-J-004 预判-验证循环）

每只 A/B 级候选 + 全部持仓，追加写入 `predictions/predictions.csv`：
- 判断内容 = 次日预期开盘方式与强弱（如"高开2-4%维持红盘"）
- 依据条目 = DT-xx-nnn；触发/目标条件与失效条件写具体可验证口径
- 时间框架 = 1 个交易日

## 第 7 步：产出报告

- 会话内交互看板（visualize）：情绪仪表盘 + 主线图谱 + 候选分级表 + 持仓点评
- 存档 `reports/daily/D/晚间复盘.md`（含全部依据条目引用）
- 情绪指标写 `data/snapshots/D/sentiment.json`（时序积累）

## 纪律提醒（每次复盘必附）

- 情绪退潮期基调 = 空仓/轻仓，A 级候选只观察不接力（DT-J-017）
- 无心仪图形不出手（DT-R-029）；预判写盘前，执行只在盘中验证（DT-J-020）
- 台账不可事后补记
